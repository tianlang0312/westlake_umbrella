# 《一伞烟雨》—— 油纸伞非遗智能交互体验设计提案

> 课程：《智能交互与体验设计》
> 选题：自主命题 · 杭州地区传统文化/非遗技艺
> 载体：油纸伞（以杭州余杭纸伞为主要工序蓝本，视觉与文化素材借鉴西湖绸伞与西湖文化生态）

---

## 一、创意主题概述

### 1.1 主题命名

**《一伞烟雨 · 执伞入画》**

- "一伞烟雨"：取自江南烟雨意象（呼应中国伞博物馆"江南烟雨"沉浸式投影），一把伞即是一方江南；
- "执伞入画"：用户"执"起伞，便"走进"伞面上的西湖山水——体验即入画。

### 1.2 核心创意主张：**开伞即开卷**

伞最本质的动作是"开"与"合"。我们将这一个动作贯穿全产品：

> **伞撑开 = 画卷展开 = 故事推进 = 文化被"打开"。**

- 知伞环节：页面滚动即"开伞"，卷轴式展开油纸伞的千年历史；
- 制伞环节：亲手做一把伞，让它具备"被打开"的资格；
- 撑伞环节（核心交互）：**用真实的手势撑开虚拟的伞**——张手即开，伞面浮现西湖十景，雨滴落上伞面被弹开；
- 收束环节：手势体验落幕、雨渐停，这把亲手撑过的伞化作一张可保存分享的数字纪念卡。

一把伞串起"知—做—用—留"的完整文化体验闭环。

### 1.3 三个创意关键词

| 关键词 | 含义 | 对应设计 |
|--------|------|----------|
| **动作即语义** | 手势开合与伞的开合同构，不需要学习成本 | 撑伞舞台手势交互 |
| **雨为叙事** | 油纸伞因雨而生，雨既是氛围也是反馈机制 | GLSL 雨滴粒子：开伞挡雨、收伞淋雨 |
| **人人共创** | 每位用户都留下"自己绘制的伞面" | 绘伞成韵模块 + 数字纪念卡 |

### 1.4 体验主线（三幕结构）

```
第一幕 知伞 —— 滚动长页，图文/动效了解历史·材料·工序
第二幕 制伞 —— 六步虚拟制伞 + 绘伞成韵个性化创作
第三幕 撑伞 —— 摄像头 AI 手势撑伞，落幕生成数字纪念卡
```

## 二、内容文本框架

### 2.1 第一幕 · 知伞（H5 知识浏览）

内容按"滚动即开伞"的长页叙事组织，共五个段落：

| 段落 | 内容 | 呈现方式 |
|------|------|----------|
| ① 序章 | 江南烟雨中一把伞缓缓撑开，引出主题 | 全屏 WebGL 开场动效 |
| ② 溯源 | 油纸伞千年简史：从"华盖"到民间雨具，至余杭纸伞、西湖绸伞的杭州脉络 | 横向时间轴 + 关键节点卡片 |
| ③ 解构 | 一把伞的结构：伞骨、伞面、伞柄、糊纸、刷油；以余杭纸伞约 72 道工序为例 | 3D 伞分解图 + 可点击热点 |
| ④ 格物 | 材料馆：毛竹（骨）、桃花纸（面）、柿漆（裱）、桐油（防水） | 点击材料样本弹出说明动效 |
| ⑤ 转场 | "纸上的伞是别人的，手上的伞才是自己的" → 引导进入制伞 | 全屏文案过场 |

> 设计依据：呼应调研中"文化认知需求——低学习成本理解工艺特色"及伞博物馆"结构探索、动态开合展示"方向。

### 2.2 第二幕 · 制伞（六步工序 + 个性化）

六步工序，每步 = 一个轻量交互 + 一个知识彩蛋：

| 步骤 | 用户操作 | 视觉反馈 | 穿插科普 |
|------|----------|----------|----------|
| 1 选竹 | 点击挑选粗细合适的竹段 | 不合格竹段碎裂消失，选中竹段劈开 | 竹龄与韧性的关系 |
| 2 削骨 | 拖拽打磨伞骨 | 竹屑粒子飞散，骨条渐现弧度 | 伞骨数量与伞面张力 |
| 3 组装 | 点击对位，依次撑起伞骨 | 骨架从收拢到张开 | "伞骨套合技艺"（西湖绸伞特色） |
| 4 糊面 | 长按裱糊桃花纸 | 纸面贴合伞骨，接缝消失 | 柿漆粘合的防水原理 |
| 5 绘纹 | 画笔在伞面绘制/选贴纹样 | 笔迹实时映射到 3D 伞面 | 纹样寓意（荷花=和合、山水=栖居） |
| 6 刷油 | 长按刷桐油 | 伞面光泽渐现（GLSL 光照变化） | 桐油防水，"纸伞不惧雨" |

**绘伞成韵（个性化模块）**
- 提供西湖山水、荷花、花鸟、烟雨四套元素库；
- 可自由配色、调整纹样布局，3D 伞面实时预览；
- 完成后自动保存为"我的伞面"，供第三幕使用。

> 设计依据：直接承接调研案例二"十二生肖 IP 填色绸伞"的启示——数字化放大纹样选择与实时预览优势；对应"个性化创作需求"与宋记绸伞"非遗 + 个性化创作结合"的潜在需求。

### 2.3 第三幕 · 撑伞（AI 手势核心交互）

**场景设定：** 江南雨景三维舞台。细雨落下，中央悬着用户在第二幕制作的伞。

**手势规则表：**

| 手势 | 识别依据 | 场景反馈 |
|------|----------|----------|
| 张开手掌 | 指尖到掌心平均距离增大 | 伞徐徐撑开，伞面浮现"我的纹样 + 西湖十景" |
| 握拳 | 距离减小 | 伞收拢，雨滴直接落下 |
| 移动手掌 | 手部中心点 X/Y 坐标 | 控制伞在雨中移动，追逐遮挡 |
| 转动手腕 | 手部朝向（进阶，可选） | 伞面旋转，展示不同扇区 |

**招牌瞬间：开伞挡雨。**
伞撑开的一瞬，雨滴打在伞面上碎成水雾顺弧面滑落（GPU 粒子 + Bloom），配一声开伞闷响——让用户用身体"验证"了油纸伞防水这件事。收伞则雨落无遮。开合之间，功能即体验。

**彩蛋知识点：** 伞面按伞骨分为若干扇区，每扇区对应一景（断桥残雪、苏堤春晓……），把伞转/移到镜头近处可触发该景的短知识。

**体验收束：伞卡留影。**
手势体验结束后，雨势渐停，镜头缓缓拉近撑开的伞，生成**专属数字纪念卡**（含用户绘制的伞面、配色、作品名、一句伞谚），可保存图片、扫码带走——把"体验过"变成"留下来"。

> 设计依据：呼应案例《瞬息 INSTANT》（伞开合作为核心交互动作）与《和傘之陣》（伞的动作转化为控制方式），对应"互动参与需求"；纪念卡收束对应"体验成果留存需求"（调研·用户需求 4）。MediaPipe 手势识别扣紧课程"智能交互"主题。

```
┌─ 知伞 · 长页分段 ───────────────────────
│ ① 序章：全屏雨景，伞缓缓撑开（滚动触发）
│ ② 溯源：──1930──1960──1990──2020──  时间轴

│            ·热点1 伞骨  ·热点2 伞面 …
```

说明：页面每滚动一段，伞的"打开程度"同步推进（开伞进度 = 滚动进度），保证"开伞即开卷"隐喻贯穿。

## 四、技术执行路线

### 4.1 技术栈总表

| 模块 | 核心技术 | 承担职责 |
|------|----------|----------|
| 一幕 知伞 | Three.js + GSAP(ScrollTrigger) | 滚动叙事、开伞动效、热点交互 |
| 二幕 制伞 | Three.js + Canvas 纹理 + GLSL Shader | 工序交互、绘纹实时贴图、桐油光泽 |
| 三幕 撑伞 | MediaPipe Hands + Three.js + GPU 粒子(FBO) + Bloom | 手势识别、开合驱动、雨滴粒子、纪念卡导出 |
| 通用 | 原生 JS / Vite 打包，Web Audio 音效 | 全程 Web，扫码即开、免安装 |

### 4.2 分阶段实施（按里程碑推进）

| 阶段 | 内容 | 产出 / 验收标准 |
|------|------|------------------|
| 阶段〇 技术验证 | 双 Spike 并行：① Three.js 伞骨建模 + 雨滴粒子 + Bloom；② MediaPipe 张手/握拳识别稳定性测试 | 两个可运行 demo；手势识别在正常光照下稳定区分开/合 |
| 阶段一 知伞+制伞 | 长页叙事 + 六步工序 + 绘伞成韵 | 完整跑通"浏览→做出一把自己的伞" |
| 阶段二 撑伞 | 手势接入舞台：开合映射 + 雨伞粒子联动 + 手动模式降级 + 纪念卡收束 | 无鼠标纯手势可完成一次完整开合，纪念卡可导出 |
| 阶段三 打磨联调 | 全链路串测、录屏备份、答辩演示包（U 盘离线版） | 断网/无摄像头两种极端场景均可演示 |

## 五、汇报叙事建议（5 分钟口径）

1. **背景（30s）**：杭州客流数据 + 青年非遗偏好数据 → 引出"伞文化有场景、缺轻交互"的机会；
2. **主题（1min）**：《一伞烟雨》命名释义 → 核心主张"开伞即开卷" → 三幕主线一页图；
3. **流程走查（2min）**：按草图框架逐屏讲知伞→制伞→撑伞，重点停留"开伞挡雨"招牌瞬间，以纪念卡收束；
4. **技术路线（1min）**：技术栈总表一张图 + 阶段〇已完成的双 Spike 结论（可行性证据）；
5. **收尾（30s）**：里程碑计划与分工收尾。
