# 伞间西湖 · 烟雨绸伞数字雅集

《智能交互与体验设计》课程完整网页工程。本版在原始 `westlake_umbrella-main` 项目上进行了 **烟雨西湖主题的完整页面视觉重设计**，同时保留了原有项目的所有功能入口。

## 运行方法

1. 解压后进入包含 `app.py` 的 `westlake_umbrella-main` 目录。
2. 安装依赖：`pip install -r requirements.txt`
3. 启动：`python app.py`
4. 在 Chrome / Edge 打开 `http://127.0.0.1:5000`

> 请不要直接双击 HTML 文件：上传图片的国风处理依赖 Flask 后端。Three.js 与 MediaPipe 使用 CDN，初次加载 3D 和手势识别功能时需要可以访问相关网络资源。摄像头权限需通过 localhost 或 HTTPS 访问并由用户主动授权。

## 视觉更新 · 烟雨西湖

- **首页**：双栏书卷式排版，浅墨远山、宣纸留白、环形伞面舞台、雾化动效、诗词引导、朱印点缀。
- **第一卷·知伞**：水墨长卷式滚动叙事，右侧三维伞模型与故事同步展开。
- **第二卷·制伞**：绢白工坊侧栏、淡竹纹样、国风画板、浅墨背景的实时三维舞台。
- **第三卷·听雨**：将原本深色雨夜更换成浅墨烟雨西湖，新增手势心法说明卡；保留摄像头/手动交互和开合滑杆。
- **纪念卡**：保留作品命名与图片导出。
- **默认伞面**：改为用户提供的山水画参考图衍生的柔雾丝绸纹样；不再采用硬色块图案。
- **响应式**：支持桌面端、平板与手机排版，推荐课堂演示使用 1440 × 900 或 1920 × 1080。

主题配色：绢丝米白 `#E9E2D2`、西湖青绿 `#86A59A`、荷花淡粉 `#D8A6A1`、竹墨深青 `#334A48`。

本版用于视觉设计的两张水墨山水图，来自用户提供的参考图片，已放置于 `static/assets/`。

## 核心功能（均保留）

- 真实连续收拢：16 根演示伞骨，纵向褶皱、滑动伞巢、收束系带；不再是直接缩放圆盘。
- 三维模型拖拽旋转、滚轮缩放。
- 选竹、削骨、组装、绷绸、绘纹、收饰六步**教学简化工序**。
- 用户上传 JPG / PNG / WebP / BMP，选择「空灵水墨」「工笔淡染」「江南淡彩」传统图像处理效果并映射至伞面；**不是生成式 AI 风格迁移**。
- 用户自定义绘画、纹样库与伞面缩放/旋转。
- 张掌开伞、握拳收伞、移动手掌旋转观察角度；无摄像头时可用手动按钮与滑杆。
- 完成互动生成个人纪念卡 PNG。

## 技术说明

1. 网站设计与图像处理均在本地运行；前端 JavaScript 库使用外部 CDN，初次运行要求网络环境可访问。
2. 人物、城市或普通照片的传统图像处理只能改善整体色彩层次，**不能保证转化为图 2 / 图 3 那种经过人工构图的完整国画**；如有此需求，需要训练好的图像重绘模型或外部生成服务。
3. 真实绸伞的骨数和工艺流程因产品不同而变化，本项目出于交互演示的流畅度使用 16 根伞骨及简化的六个教学步骤，不等同于非遗工艺的全部步骤。
4. 西湖绸伞始创于 1932 年，以淡竹和杭州丝绸为主要材料，传统装饰工艺包括刷花、彩绘、刺绣。工艺资料参见中国非物质文化遗产网：`https://www.ihchina.cn/project_details/14578/`。
