# 一伞烟雨 · 油纸伞非遗智能交互体验

《智能交互与体验设计》课程作品。以杭州油纸伞（余杭纸伞工序为蓝本，视觉借鉴西湖绸伞）为载体的三幕式 Web 交互体验：**开伞即开卷，执伞入画**。

## 快速运行

1. 安装 Python 3.10+。
2. 在项目目录运行 `pip install -r requirements.txt`。
3. 运行 `python app.py`。
4. 浏览器打开 `http://127.0.0.1:5000`。

## 体验主线（三幕）

- **落地页**：江南雨幕 + 旋转 3D 油纸伞主视觉，扫码即入。
- **第一幕 · 知伞**：滚动长页叙事，"开伞进度 = 滚动进度"。含千年时间轴、伞结构 3D 分解热点、毛竹/桃花纸/柿漆/桐油材料馆。
- **第二幕 · 制伞**：六步工序交互（选竹→削骨→组装→糊面→绘纹→刷油），每步配知识彩蛋；绘纹环节内置西湖山水/荷花/花鸟/烟雨四套生成纹样 + 自由画笔 + 上传照片 AI 国风化（水墨/工笔/淡彩），实时映射 3D 伞面。
- **第三幕 · 撑伞**：江南雨夜舞台，摄像头 AI 手势交互——张掌开伞、握拳收伞、移动手掌移伞、转腕转伞面；开伞挡雨溅起水雾，收伞淋雨；拉近镜头可触发伞面"西湖十景"彩蛋；落幕雨歇生成专属数字纪念卡（含伞面、作品名、伞谚），可保存 PNG。

## 技术栈

- 前端：Three.js（3D 伞/雨滴粒子）、MediaPipe Hands（手势识别，连续帧防抖）、Canvas 2D（纹样生成/纪念卡）、Web Audio（合成雨声/开伞音）。原生 ES Module，无构建步骤。
- 后端：Flask + Pillow + NumPy + OpenCV，提供 `/api/stylize` 传统图像风格化接口（非深度学习）。
- 结构：`static/js/` 下为模块——`store.js`（共享纹理/状态）、`umbrella.js`（可复用 3D 伞）、`rain.js`（雨滴/水雾粒子）、`gesture.js`（手势）、`audio.js`（音效）、`views/`（落地页/知伞/制伞/撑伞）。

## 网络依赖与降级

- Three.js、MediaPipe 模型经 CDN 加载，首次需联网。
- 无摄像头环境：撑伞页提供"手动模式"按钮强制降级；鼠标拖动/滚轮全程可用。

## 局限

- 收伞通过几何半径变化近似表现，非物理精确的伞骨开合模拟。
- 图像效果是传统算法风格化，非神经风格迁移。
- 摄像头手势建议 Chrome/Edge，localhost 可直接使用；远程部署需 HTTPS。
